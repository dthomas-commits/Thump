Map files: public/maps/<song-id>.json  (song ids: sky-high, fade, the-spectre, fluffing-a-duck, cradles, nekozilla, montagem-india)
Format: {"id":"sky-high","offset":0,"notes":[[seconds,"left|up|down|right"], ...]}
seconds = time from the very start of the song. "offset" shifts the whole map (e.g. -0.05 = 50 ms earlier).
A map file replaces the automatic chart for that song. Easiest way to make one: use the ● MAP button next to a song in the game, tap arrow keys along with the music, press Esc, then move the downloaded .json into this folder.
